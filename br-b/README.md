# VulnPriority — BR-B 논문 기반 취약점 점검 도우미

**기반 논문:** 2024년 공개 취약점의 CVSS v3.1 심각도와 CISA KEV 등재 비율의 연관성 분석

**대상:** 보안점검 담당자와 취약점 관리 학습자.

**앱 한 문장:** 취약점 점검 담당자가 CVSS 점수와 KEV 등재 여부를 확인할 때, T10 논문의 분석 결과를 활용하여 추가 점검에 필요한 근거와 확인 사항을 안내하는 앱입니다.

## 앱에서 할 일 세 가지

1. `index.html`을 열고 CVSS v3.1 점수(0.0~10.0, 소수 첫째 자리까지)를 입력한다. `9.8`이나 `6.5` 예시 버튼을 눌러도 된다.
2. CISA KEV 등재 여부를 선택한다. 실시간 조회 기능은 없으므로 CISA 공식 목록에서 확인한 뒤 선택한다.
3. **논문 근거로 점검 결과 보기**를 눌러 해당 심각도 구간의 표본 수, KEV 등재 비율과 다음 점검 사항을 읽는다.

## 실행 방법

- `index.html`을 더블클릭해 Chrome/Edge 등 브라우저에서 연다. 인터넷 연결이나 로그인, 서버, 패키지 설치가 필요 없다.
- 압축 파일로 받았다면 **새 폴더**에 완전히 압축 해제하고 `index.html`을 연다.
- 옵션: Node.js 18 이상이 설치되어 있으면 폴더 최상단에서 `node --test tests/core.test.cjs`를 실행해 테스트 4개를 확인한다. **테스트는 앱 사용의 필수 조건이 아니다.**

## 연구 데이터의 근거와 한계

- T10 논문 분석 시점: 2024년 공개 CVE, CISA KEV 목록은 2026-10-16 기준.
- 분석한 CVE: 총 32,102건, KEV 등재 총 149건.
- None: 1건 / 등재 0건 (0%), Low: 626건 / 1건 (0.15974%), Medium: 15,993건 / 13건 (0.08129%), High: 11,251건 / 70건 (0.62217%), Critical: 4,231건 / 65건 (1.53628%).
- **이 비율은 심각도 구간별 과거 표본의 KEV 등재 비율이며, 입력한 개별 취약점의 악용 확률이 아니다.**
- KEV 미등재는 미악용 또는 안전의 증거가 아니다. Low 비율이 Medium보다 높았던 예외(등재 1건)도 논문 그대로 표시했다.
- 앱은 CVE 번호 입력이나 온라인 목록 자동조회 기능이 없다. 사용자가 직접 확인한 KEV 상태에 따른 추가 점검 안내만 제공한다. 실제 보안 의사결정에는 자산 영향·노출도·중요도·패치 가능성 등 별도 확인이 필요하다.

## 데이터 보안 및 환경 변수

- 고정 공개 집계치와 임의 예시 점수만 사용하며, 실제 개인정보·자산 정보·토큰·비밀번호를 수집하거나 전송하지 않는다.
- 외부 JS·스타일 라이브러리 없음. **API 키 불필요, 환경 변수 없음.**

## 파일 안내

- `index.html`: 실제 앱 화면 및 연구 차트.
- `styles.css`: 반응형 화면 스타일.
- `core.js`: 논문 숫자, 점수 검증, 결과 안내(순수 함수).
- `app.js`: 사용자 입력과 화면 렌더링.
- `tests/core.test.cjs`: Node.js 표준 라이브러리 테스트.
