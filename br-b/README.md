# VulnPriority v2 — BR-B 논문 기반 취약점 점검 도우미

**기반 논문:** 2024년 공개 취약점의 CVSS v3.1 심각도와 CISA KEV 등재 비율의 연관성 분석

**대상:** 보안점검 담당자와 취약점 관리 입문자.

**앱 한 문장:** 제품명·서비스명·CVE 번호로 공개 취약점 정보를 찾아 CVSS v3.1 및 KEV 상태를 확인하고, T10 논문에서 관찰된 심각도별 KEV 등재 비율과 추가 점검 기준을 안내합니다.

## 처음 온 사람이 하는 일 세 가지

1. **제품명·영문 키워드로 검색:** 예시 버튼 OpenSSH/Log4j/Fortinet 중 하나를 누르거나 제품명을 입력한다. CVE 번호를 미리 알 필요가 없다.
2. **검색 결과에서 CVE 선택:** 공식 공개 데이터에서 조회한 CVSS v3.1 점수와 KEV 등재 상태가 아래 분석란으로 채워진다. 정보가 없거나 조회 실패하면 없음/실패로 표시하며 임의 점수를 만들지 않는다.
3. **논문 통계와 점검 안내 확인:** 분석 버튼으로 2024년 표본의 심각도별 등재 비율과 추가 확인 사항을 읽는다.

**보조 흐름:** 검색하지 않고 CVSS 점수와 본인이 CISA에서 확인한 KEV 상태를 직접 입력할 수 있다. 인터넷이 없는 경우에도 이 부분과 고정 논문 통계는 작동한다.

## 공개 URL

- 앱: https://vulnpriority-br-b.vercel.app/
- 포트폴리오: https://project-br-a.vercel.app/#projects
- 논문: https://project-br-a.vercel.app/research.html

공개 Vercel 앱에서 검색은 공식 NVD CVE API 2.0과 CISA KEV JSON을 사용한다. 계정이나 AI 서비스 키는 필요 없다.

## 실행 및 테스트

- 온라인 검색은 Vercel 배포 앱과 서버리스 함수 api/search.js에서 제공한다.
- 오프라인/ZIP은 새 폴더에 압축 해제하고 index.html을 열면 수동 점수·KEV 입력 및 논문 통계 확인이 가능하다. **제품명/CVE 검색은 서버리스 API가 필요하며 로컬 HTML만으로는 실행되지 않는다.**
- Node.js 18 이상에서 node --test tests/*.test.cjs 로 오프라인 테스트할 수 있다. 테스트는 고정 예시 기반이며 공개 API 가용성을 증명하지 않는다.

## 논문의 고정 통계 (2024년 공개 CVE / KEV 2026-10-16 기준)

- 분석 표본 32,102건, KEV 등재 149건.
- None 1건/0건(0%), Low 626건/1건(0.15974%), Medium 15,993건/13건(0.08129%), High 11,251건/70건(0.62217%), Critical 4,231건/65건(1.53628%).
- Critical/Medium 등재 비율 약 18.9배. 이는 집단별 KEV 등재 비율이며, **개별 CVE의 악용 확률이나 검증된 조치 우선순위를 뜻하지 않는다.**
- Low 비율이 Medium보다 높은 예외와 KEV 미등재가 악용 부재를 뜻하지 않는다는 한계를 숨기지 않는다.

## 공개 조회 정보와 한계

- NVD는 제품명/키워드 및 CVE ID 조회를 제공한다. CVSS v3.1 점수가 존재하는 경우에만 표시하며 CVSS v4.0 점수를 임의 환산하지 않는다.
- CISA KEV 공개 목록이 연결되지 않으면 미등재와 확인 불가를 구별한다.
- NVD 장애 시 CISA KEV 목록만 검색할 수 있는 대체 경로가 있고, 그 경우 점수는 채우지 않는다.
- 현재 조회하는 CVE는 원 논문의 2024년 고정 표본에 포함되지 않을 수 있으며, 서로 다른 시점의 데이터를 섞어 악용 확률을 산출해서는 안 된다.

## 개인정보와 비밀값

- 공개 취약점 데이터와 논문 고정 집계치만 사용한다. 자산 정보·계정·연락처·비밀번호·토큰은 입력하도록 요구하지 않는다.
- 키나 환경 변수 없음. API 서버는 사전에 정해진 NVD 및 CISA 공개 주소에만 요청한다.
- 사용자가 검색한 제품명/CVE 키워드는 공개 데이터 조회를 위해 서버·NVD로 전달되므로 내부 시스템명이나 비밀값을 입력하지 않는다.
- 외부 텍스트는 DOM의 textContent로만 출력한다.
