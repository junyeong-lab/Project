# 🐥 뭐따지? (Muttaji)

**AI가 알려주는 나만의 취업 준비 가이드**

> 채용공고를 입력하면 요구사항을 분석하고 사용자 역량과 비교하여, 무엇을 준비할지 실행 순서로 알려주는 웹앱 MVP 프로젝트.

## 현재 상태 (2026-10-21)

- **완료:** 서비스 기획, 브랜드/캐릭터 및 UI 시안, 발표자료, 자격증 DB 초기 Excel 템플릿, [프로젝트 계획서 v2](./plan.md)
- **진행 전:** 자격증 공식 정보 검증, 실제 웹 UI, 이미지·텍스트 분석 API, 역량 비교, 자격증 추천, 로드맵, 배포
- 이 저장소의 `muttaji/` 디렉터리는 기존 ALEPH 과제 코드와 분리하여 관리합니다.
- 초기 템플릿과 디자인 시안은 **운영 DB나 작동하는 앱이 아닙니다.**

## MVP의 핵심 흐름

채용공고 텍스트/이미지 → 필수·우대 요건 구분 → 내 역량 입력·비교 → 공식 검증된 자격증 정보 매칭 → 취업 준비 로드맵

- 퍼센트 적합도·합격 확률을 임의로 산출하지 않습니다.
- 자격증 보유를 실무 경력 충족으로 간주하지 않습니다.
- 채용공고 URL 크롤링, Google Play 출시, 결제는 초기 MVP 범위가 아닙니다.
- 기존 「뭐따지?」 병아리 디자인을 유지하고, 원본 디자인 자료가 확인된 뒤 UI에 반영합니다.

## 진행 순서

1. 자격증 DB 스키마 및 공식 정보 검증
2. 기존 UI 기반 웹앱 화면
3. 채용공고 텍스트·이미지 분석
4. 사용자 역량 비교 및 자격증 추천
5. 맞춤형 준비 로드맵과 예외 처리
6. 실제 공고 테스트 및 Vercel 배포

## ALEPH 점검

- **중간 점검 1차:** DB와 기본 화면이 확인 가능한 단계에서 실제 진행 현황으로 작성 (예정)
- **중간 점검 2차:** AI 분석·역량 비교·로드맵의 실제 작동을 점검하며 작성 (예정)
- **최종 제출:** 실제 배포 URL과 구현·테스트 결과를 확인한 뒤 작성 (예정)
